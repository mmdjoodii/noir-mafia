# Noir — Mafia Moderator App

وب‌اپلیکیشن موبایل‌محور Noir برای تقسیم دستی یا تصادفی نقش‌های سناریوی دمیج و مدیریت HP بازیکنان.

## اجرا

نیازمند Node.js 20+ و npm است.

```bash
npm install
npm run dev
```

برای تست روی گوشی، کامپیوتر و گوشی را به یک شبکه وصل کنید و آدرس شبکه‌ای Vite را در مرورگر گوشی باز کنید.

## ساخت نسخه تولیدی

```bash
npm run build
npm run preview
```

## امکانات پیاده‌سازی‌شده

- ثبت نام ۱۰ بازیکن
- تقسیم دستی یا تصادفی ۱۰ کارت نقش سناریوی دمیج؛ نمایش محرمانه کارت‌ها به‌ترتیب
- نمایش کارت نقش با نگه‌داشتن انگشت؛ رهاکردن، کارت را پنهان می‌کند
- داشبورد گرداننده با نام، نقش و HP بازیکنان
- کسر سریع ۵، ۱۰، ۲۰، ۴۰ و ۱۰۰ HP
- انتخاب علت‌های آماده برای تغییر HP (چالش، آشوب‌گر، شات‌ها، سم‌ساز، هیلر، حکیم و جعبه جادوگر) به‌همراه افزایش یا کاهش دلخواه
- رولت روسی درون سناریو: انتخاب دو بازیکن و یکسان‌سازی HP هر دو بر اساس میانگین HP فعلی‌شان
- جعبه جادوگر در فهرست علت‌های روز قرار دارد
- ثبت سوابق تغییرات HP و بازگردانی آخرین تغییر
- مدیریت مرحله‌ها: روز معارفه، شب معارفه، روز ۱، شب ۱ و ادامه روز/شب‌های بعد
- روز معارفه بدون رأی‌گیری و چالش؛ شب معارفه فقط برای آشنایی مافیاهاست
- ذخیره خودکار در localStorage
- رابط فارسی و راست‌چین با طراحی اختصاصی موبایل
- تصاویر کارت هر سناریو در پوشهٔ مستقل خودش نگهداری می‌شود: `public/cards/damage/` و `public/cards/bazpors/`

## تصمیم‌های فعلی و محدودیت‌ها

- HP اولیه فعلاً ۱۰۰ است و در `src/scenarios/damage.ts` قابل تغییر است؛ این مقدار هنوز به‌عنوان قانون رسمی سناریو تأیید نشده است.
- ترکیب نقش‌ها بر اساس اطلاعات فعلی پروژه تعریف شده است: ۹ نقش یکتا و ۱۰ کارت، با دو کارت شهروند ساده.
- Abilityها و قوانین اختصاصی سناریو به‌صورت خودکار اجرا نمی‌شوند.
- اطلاعات در همان مرورگر و در `localStorage` ذخیره می‌شوند؛ پاک‌کردن داده‌های مرورگر می‌تواند بازی را حذف کند.
- تغییر تکی نقش پس از تقسیم پیاده‌سازی نشده؛ امکان شروع مجدد تقسیم وجود دارد.
- پروژه فعلاً بک‌اند، حساب کاربری و همگام‌سازی بین دستگاه‌ها ندارد.
- کارت‌های دمیج و بازپرس در پوشه‌های جداگانه‌اند؛ برای بازپرس از نسخه‌های تصویری WebP موجود در فایل ارسالی استفاده شده است.

## ساختار اصلی

```text
src/
  types/        شکل داده‌های مشترک برنامه
  game/         قوانین مشترک: تخصیص نقش، مراحل عمومی و وضعیت بازیکن
  scenarios/
    damage/     منطق اختصاصی دمیج: HP، علت‌های HP، رولت و فرم HP
    bazpors.ts  داده‌های سناریوی بازپرس
    damage.ts   نقش‌ها و ترکیب سناریوی دمیج
  hooks/        هوک‌های عمومی React (تقسیم نقش، ذخیره، toast)
  services/     ارتباط با بیرون از برنامه (ذخیره در localStorage)
  utils/        ابزارهای کوچک و عمومی (شناسه، فرمت فارسی، بُر زدن)
  screens/      صفحه‌های تمام‌صفحه
  components/   تکه‌های قابل استفاده مجدد (پنل‌ها، دیالوگ‌ها)
  App.tsx       هماهنگ‌سازی جریان رابط کاربری و اتصال سناریوها
  index.css     استایل پایه و RTL
public/cards/damage/   کارت‌های سناریوی دمیج\npublic/cards/bazpors/  کارت‌های سناریوی بازپرس
```
